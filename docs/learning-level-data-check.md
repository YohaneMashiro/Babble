## 进度和用户库

- 原四码及专项进度键保持原样。例如 `某:MZGM:0123` 和 `某:MZGM:01` 不变；新增双拼使用 `某:MZ:01`，两级完成不会合并为同一掌握目标。新增课程使用 `shuangpin-` ID；原课程游标不迁移、不清空。
- 快照恢复仍接受合法旧四码记录，并新增两码记录支持；两码记录若含位置 2、3 会被拒绝。原始错误记录的保留及内存降级策略继续适用。
- `useLearningProgress()` 位于共享 `App`，进度快照、同步引用和有序写入队列不会随带级别 `key` 的训练区卸载。切级先结算当前未完成尝试，再重建训练区；已完成尝试不会再次结算。
- `userEntries` 和启动恢复版本号同样位于共享 `App`。应用／清除用户库立即更新共享内存，恢复请求只有版本号仍一致才可写回，因此切级不会重新恢复旧库覆盖本次选择。
- 用户库存储模块与原版字节相同。保存与清除继续使用模块级有序队列，读操作等待此前写入。导入界面在等待可选持久化前已经同步调用应用回调；关闭界面或切级不会撤回已应用的临时库。对话框的 `autoRestore={false}` 避免再次恢复覆盖共享状态。
- 双拼级别不把用户四码或 OK 编码当成本字读音；它们在共享内存中保留，返回音形级别后可继续使用。文章、逐次选读和位置只留本次页面内存；切级会使旧文本提交请求失效。
