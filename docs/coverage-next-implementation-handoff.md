## 1. 生产生成器与资料资格

移植[研究程序](../tools/coverage-next-research/README.md)的固定政策，做正式参数化生成器；不要让产品依赖`/root/.cache`绝对路径。锁定原输入、许可、程序／政策、Unicode身份属性、拼读运行时和派生产物。

1. 现代属性与上游助记取并集；额外词典属性逐项保留文件、行号、字段和选读身份。香港词典只取已明确提取的Mandarin部分，不引入粤语到普通话拼读。
2. 采用固定新版Yi、CHISE及原radical／chaizi替代拆分。保留IDS拓扑、地区／来源标签、显式命名等价和原行。不能靠相似字形或期待码补部件。
3. Unicode等价字形迁移明确属于助记候选；保留原部件、目标字和映射行，不修改用户原文，不声称Unicode证明二者发音相同。
4. 每个有稳定身份的两部件源切分，只展开其中一个命名部件，采用其有来源的两部件定义得到三部件。保留父与子见证，不无限递归，不互换不同未知形。
5. `□`、替代字符、PUA及其他无稳定身份对象不能作为跨来源命名等价。身份来自固定Unicode属性／明确笔画定义；锁定字符名数据库版本，不能随执行机升级悄悄改变政策。
6. 生成完整候选和摘要后，才读项目外固定参照逐字码对比较。保持每源结构组合上限、循环检查和拒绝原因；本轮观察最大84音码组合、24新结构／外层切分、零上限丢弃，移植输出需逐项说明差异。

参考原件不打包。正常离线`--check`只核验固定输入与分发产物，不伪称无原件也重新做了官方比较；重建需显式传入固定外部参照，禁止自动换源重锁。

## 2. 增量分片与旧目标保留

推荐集合共有1,383,071个研究候选对，正式一致拼字只有70,785字／70,837对。**不把全部研究候选塞进首页或默认答案。** 保留已有只读候选功能；新未一致资料继续留研究／构建审查层，若日后接查询也须明确候选身份。

优先新增与旧已确认对的差集，采用可逆元组和按Unicode区域分片；合并查询时保留原字、码、父子部件、字段来源与比较状态。旧v1同字码对沿用原证据和原target key，不因v2来源政策更名而丢失已有连胜／掌握。新码对使用新方案身份，普通四码仍优先。

不要把额外部件读音全量写入整字的现代默认读音索引。部件读音至少区分：原现代读音、上游助记、旧／地区词典选读、公开约定、等价字形助记。用明确类型显示人可理解的来源，不依赖字符串是否包含`mnemonic`来猜新身份。

Inspector分别呈现本字读音、普通四码、已确认拼字和教学范围；有已确认拼字而原读音索引缺字时，不能只用“本地数据库尚未收录”概括整个字的状态。

只在查询或文本准备时载入新分片。加载期间不能先当缺字跳过；失败／重试／切换时保留原文、码位前缀和仍有效的选择。实体按键不逐键联网；原三主模式与用户文件隐私边界不变。

## 3. 七个有限端点字与命名根

采用[常用字来源研究](coverage-next-common-characters.md)的七字八个通过码对：生、大、见、升、断、继、夜。无的普通四码继续留语境复核；它已由拼字路径补足。见只接纳jiàn的已比较码对，xiàn仍是未通过／仅读音状态，不随整字升级。

这些字目前都没有普通四码，预计普通字数8,302→8,309、带调选项8,978→8,986；大已有拼字，整体并集只因其余六字新增。最终必须由实际生成物计算，不能为了匹配预期改筛选。

增加可表示稳定ID、类型、名称、可选单字形符、键位、来源定位、适用语境和笔画范围的根引用。见下是命名部件，不替换成儿；尢作为嵌套部件与分析其自身的首末捷径分开。单笔保留实际路径／符号，按既有六类笔画解释捺、折，不能把非笔画根任意归一。

前端码位显示短名称，详细身份／来源在解释区展开。断、继、夜的中间灰区明确未展开；不自动加入完整取根教学课或旧键位定义。新解释的披露继续算协助，完成后的回顾不追改成绩。

Arphic笔画矢量、LGPL字典路径、AGPL根事实和原创程序分别保存通知及修改说明；原图形数据不能套用Hanzi Writer程序的MIT。可先提供文本端点／笔画范围，再按来源条款独立分发小型按需图形资产。

## 4. 有意义的验收

- 从原件独立重跑、比较新候选／来源链／摘要，确认没有CJKVI父或子路径混入默认资料；占位符、循环、上限、地区标签和字段身份都有负例。
- 重算旧／新字码对集合，确认原生产条目和目标key不变；同字另一码不能因一码通过而升格。验证named根及stroke符号的显示和源范围。
- 用真实生产分片重算不同字、码对、现代查询、普通四码、拼字、候选与教学范围；HY至少一码覆盖可达全量，多音仍按原规则处理。
- 运行必要单测、严格类型检查、离线资料检查与生产构建。更新来源通知、生成锁、完整对应源码及排除项，不附官方原表或私人文件。
- 三引擎回归原自由／课程／文本／教学，加真实新增字、命名根、六／八码、资料失败重试、协助、旧记录、用户库冲突、UTF-8／上限、320px／深色／axe及字形缺口；不把自动WebKit当真iOS。
- 同一探针、同类文件系统和服务交错比较启动与加载后输入；保留原始样本。不能因为编译期用了大数据就宣称首屏也必须加载全部数据。

每阶段经独立checker核对生产字节、实际行为和源码包后再报本阶段Go。研究通过不代替工程通过。
