# 15 分钟本地学习检查

准备日期：2026-10-28（Asia/Dubai）。状态：协议与空白记录已准备，**尚未进行真人试用，没有学习成效结论**。本协议不招募、不联系他人、不创建账户、不新增产品问卷或追踪。

由用户自行邀请愿意参与的人，在本机运行 Babble。分别记录从未学过双拼的初学者，以及已会双拼、开始学鹤形的使用者；两组结果分别讨论。事先告知：观察的是网页是否讲得清楚，可以随时停下，不评价个人能力。观察者先读完评分参考，但不要提前把参考答案讲给学习者。

使用空白记录模板，不记录姓名、邮箱、粘贴文章原文或其他可识别信息；不要录屏或自动上传。只记任务动作、提示使用和匿名概念回答。如学习者自愿用自定义文本，记录“曾使用自定义文本”即可。应用现有的本地单字练习记录仍按产品说明保存；使用临时浏览器资料或在试用结束后由参与者自行决定是否保留。

## 流程（总计约 15 分钟）

| 时间 | 学习者任务与观察者提问 | 要记录的证据 |
| --- | --- | --- |
| 0–2 分钟 | 说明体验目的、确认可以停止；只问是否学过双拼及小鹤。打开默认自由学习。 | 经验组别、设备与输入方式、初次看见页面后做了什么。 |
| 2–5 分钟 | 让学习者自行使用学习路径中的概念课。已会双拼者可以直接跳到形码；不要要求每个人完成相同课数。 | 是否找到适合自己的入口，卡住时页面是否提供足够指引。 |
| 5–8 分钟 | 让学习者练几个字，自行决定是否点提示、码位、汉字或键盘说明。请他用自己的话解释前两码和后两码。 | 六个概念目标的原话摘要；提示、误码及能否继续。打对四码本身不代表理解。 |
| 8–11 分钟 | 选一个尚未背过本次答案的例字（可从某、语、框、国、试中选），让学习者在同页查根、解释中间部分与首末根，然后输入。若都见过，记录“迁移样本不足”，不要假称陌生字。 | 是否自行找到理由，是否把中间根误当作形码，是否知道取根顺序与真实笔顺不同。 |
| 11–14 分钟 | 查中或鹤，说明为什么排除看似可取的口／冖；再比较建、健，说明廴在两字中的位置。允许使用同页解释，但逐项记下是否依赖提示。 | 能否说明相交排除条件、全字部首与内部部件的区别；是否注意鹤、健只展开了端点关系。 |
| 14–15 分钟 | 收起解释后，请学习者再次说出四码各代表什么，以及下次遇到不确定的字会怎样继续。询问最困惑的一处。 | 独立复述、仍需协助的概念、同页继续学习是否可行。 |

时间可以为设备或无障碍需求作调整，记录实际时长即可。没有倒计时失败。观察者只有在学习者停住或明确求助时才提供帮助，并记录帮助内容；不要把观察者讲解后的回答计为最初独立理解。

## 提问与解释评分参考（观察者使用）

每项记为“独立说明”“使用页面后说明”“观察者帮助后说明”或“尚未建立”，并附行为或原话摘要。保留回答与证据，不把模糊印象换算为百分数。

| PRD 概念目标 | 可接受的理解证据 |
| --- | --- |
| 什么是双拼 | 能说出用两次键位表达一个音节的声韵，而非必须逐个输入全拼字母。 |
| 两个音码分别代表什么 | 能按当前例字说清第一个音码与第二个音码的声韵含义。若遇到零声母，允许指出本页的零声母处理，不强迫把它称作辅音声母。 |
| 什么是鹤形 | 能说出通过汉字字形选择根／笔画，并按映射得到形码；不把它当作剩余拼音。 |
| 什么是首形 | 能在当前已复核例字中指出取根过程的第一个根及对应键。 |
| 什么是末形 | 能指出最后一个根，理解它不必等于最后书写的一笔。国、试可作为追问。 |
| 为什么最后是四码 | 能把两个音码与两个形码按顺序连起来解释；同键的不同根仍可有不同含义，如元的二与儿。 |

逐字核对参考：语有讠、五、口而形码只取两端；中因交叉不能保留口；鹤的冖被穿过，卡片只证明点、鸟端点与排除理由；建的廴为全字部首先取，健的全字部首是亻，不把内含廴一律提升为首形。木中的 ㄟ 是本库捺类的原始符号，不是要输入注音。遇到没有卡片的字，认可学习者发现“完整教学分析待补”，不要用猜测讲解弥补。

先由用户查看首批匿名记录，再确定产品通过阈值及后续样本需求。本轮不规定看似具有统计意义的完成率，不把自动化测试、模拟回答或一位学习者的成功当作总体教学成效。
