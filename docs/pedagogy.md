# Babble 教学设计

更新日期：2026-10-26（Asia/Dubai）。

## 目标与范围

让学习者在输入当前汉字时理解每一码的含义，形成「字 → 音 / 形 → 键」的可解释过程。教学、查形和键位解释都保留在当前学习上下文中。

现有 8,143 个可训练字与 44,348 字现代读音保持不变。「某」仍作首题与回归用例：`m → M`、`ou → Z`、`甘 → G`、`木 → M`，全码 `MZGM`，现代来源读音 mǒu。扩充后《花园中》可训练汉字次数覆盖率为 95.54%，但仍有 24 个不同字缺少通过核验的取形；数据是核验子集，不能宣称覆盖全部小鹤规则，详见 [data-sources.md](./data-sources.md)。

## 从单码到四码

| 位置 | 含义 | 样例解释 |
| --- | --- | --- |
| 1 | 声母 | `m → M` |
| 2 | 韵母 | `ou → Z` |
| 3 | 首形 | `甘 → G` |
| 4 | 末形 | `木 → M` |

同一按键不合并教学含义：第一位和第四位都是 M，但分别表达声母和末形。零声母两键使用来源中的专门映射并明确标注，不伪造声母。

自由学习和自定义文本练完整四码；课程按目标练声母、韵母、两个音码、首形、末形或两个形码，其他码位已经提供。只练首形时输入第三位即可完成本次目标，不要求学习者为了进入鹤形重新完成双拼。已提供位用 revealed 表示，不能当作独立答对。

## 轻量、可自由进入的路径

当前 15 课按认识小鹤、双拼基础、鹤形入门、综合四码练习组织，定义保存在数据层。所有课可直接进入，先修项只作推荐；没有必须达到某个正确率才能解锁的门槛。

学习者可以轻量选择当前程度，默认「会小鹤双拼」，用于推荐鹤形起点。完全不会的用户可以从认识小鹤开始，已有音形经验的用户也可直接选综合练习。选择不制造 onboarding 流程，也不禁止跳过。

课程示例默认折叠，学习者主动查看时才展开。课程词典语料计数排序不是现代互联网高频排名；扩展 3000 字包含缺计数的字序尾部，不能把它包装成已覆盖现代 Top 3000。

## 在自己的文本中学习

自定义文本只改变题目来源，四码解释、语义错误反馈、提示与虚拟键盘继续使用同一引擎。原文保留标点、英文、数字和换行，以每页最多 400 个可练习目标呈现；当前字在原文中突出显示，点击汉字可回到该次出现位置，重复字不会合并成一道题。

推荐文本不超过 2,000 个汉字，长文本仍可练习；超过 20,000 个 Unicode 码点时要求精简，不静默截断。空文本或没有可练习汉字的文本明确说明原因。缺少可靠取形的汉字保留在原文中并带虚线标记，自动跳过训练；点击可查读音与来源。

来源存在多音或多码时，学习者需要为本次出现明确选择，系统不猜上下文，也不把前一次同字的选择套用到后文。普通读音选择只显示读音，不属于答案提示或协助。如果同一读音有不同编码，选择界面需要显示编码来区分，本次按使用协助记录。某个读音只有来源读音而没有可靠四码时，明确不能练习，可改选或按 Enter 跳过，不能借用另一个读音的编码。

走到文本结尾只表示走完本轮顺序，不能声称所有字都已掌握；完成、纠错、协助和跳过仍按实际单字尝试分别计算。可以再练一轮或更换文本。

## 渐进提示与错误反馈

| 层级 | 当前目标可披露内容 | 第三位示例 |
| --- | --- | --- |
| 0 | 不披露目标答案 | 等待输入 |
| 1 | 语义类型 | 首形 |
| 2 | 音或部件 | 首形：甘 |
| 3 | 与键的对应 | 甘 → G |
| 4 | 完整解释 | MZGM，并保留四位含义 |

Space 请求下一层，停顿可以触发轻量自动提示。自动提示不设失败时间、不扣分、不自动换题。正确输入后下一目标位从自己的提示状态开始，但本次尝试使用过的最高提示层保留在记录中。

错误时保留已正确前缀，停在同一原四码位置；后续输入正确键即可继续，不需先删错键。例如完整四码中输入 MZJ 后说明第三位是首形，首形为甘、对应 G；首形单独练习时输入 J 也应报告原第三位错误，而不是第一位。

仅凭一个错键不能区分识形错误、键位记忆错误与手滑，无法证实时原因记 unknown。颜色之外同时提供文字或图标。

## 独立、协助与曾掌握

自动 / 手动提示、课程示例、目标码位解释、键位含义和当前目标的 Inspector 都属于协助。用了协助再完成、或出现错键后纠正完成，都不计入独立连续正确。直接提供的非目标位属于课程上下文，不因此把目标练习标为使用提示。

同一个字、完整编码与目标码位范围共同确定进度；自由学习、课程与自定义文本在相同范围内共享记录。只答对首形不能累计成全码掌握。同一目标相邻两次练习均首次独立正确，记录为「曾独立掌握」；它是可解释的简化指标，不声称等同长期肌肉记忆。

错误、提示完成、跳过或重置已开始的未完成尝试会中断当前连续记录。曾达到的掌握状态保留，不因日期自动降级，没有每日任务、streak、到期复习或时间惩罚。完成后再查看解释属于回顾，不反写该次成绩。

课程的看过表示目标已呈现，练过表示有编码输入的尝试，已掌握表示曾达到上述条件。完成一轮只表示走过本轮内容，不能替换成全部掌握；可以再练一轮或进入其他课程。

## 学习位置与查询

Enter / 下一字可以继续或跳过，Backspace 重置当前字，Esc 收起浮层。切课、回到自由学习或结束本轮会结束当前未完成尝试并保留课程位置。刷新后继续课程从上次题目重新输入，不恢复未完成的按键前缀。

点击当前汉字打开 Inspector 后，关闭仍回到原输入位置；只有明确选择练习某字才切换目标。查询框、设置与其他浮层不能误触训练按键。查看来源和完整映射按需展开，目标答案未披露前不通过高亮或 tooltip 偷先标出。

进度仅保存在当前浏览器。等待保存完成能确认记录已提交；存储受限时明确显示仅内存保存，仍允许学习，并保留原有无法安全读取的数据。没有账号、云同步或分析追踪。

文本编辑器打开时暂停训练，取消编辑后保留未完成按键；重新导入则结束原尝试，从新文章开头开始，重新选择各处读音。切换其他模式后返回会保留文章位置，但从该字重新输入；仅翻阅原文分页不会切题。清除文本后打开空白编辑器。

文章、读音选择和文章位置只保留在页面内存，刷新后清除，不随常规学习记录写入本地存储。单字尝试仍记录字符、编码与完成结果，用于同范围累计进度，但不附原文或文章位置。

## 数据缺失与教学局限

未收录字符明确显示缺失；仅读音而缺可信取形的字不能进入四码训练。多音 / 多码选项来自核验数据，不使用模型生成形码或猜语境。只有完整编码而无可信解释的条目，也不能逆推拆分补齐。

Inspector 的源 IDS 与递归路径记录生成依据，不冒充笔顺或完整教学拆字图。声韵表已经核对，字形关联只覆盖当前核验子集，不能称为全部字根。

「15 分钟后理解双拼与鹤形」仍需真实学习者验证，不能把条目数量、进度数字或交互测试当成已证实的教学效果。下一阶段继续打磨初版教学与交互，不改变来源不足时拒绝补造编码的原则。
