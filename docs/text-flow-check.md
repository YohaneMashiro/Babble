# 连续文本练习验收

日期：2026-11-01。独立检查负责方：`text_flow_qa`。

验收结论：本次连续文本界面与空格确认流程可以交付。最终生产构建在三个实际浏览器引擎中一次通过全部 14 组场景，共 42 组；每引擎 9 个 axe 视图，共 27 次，0 违规、0 未捕获浏览器错误。

## 检查范围

检查程序：[text-flow-smoke.mjs](../scripts/text-flow-smoke.mjs)。使用已有项目外 Playwright／axe，不新增产品依赖。

- 桌面文本宽度与高度增加，独立大字标题移除，参考字保持紧凑，键盘可用。
- 双拼两码、音形四码完成后等待空格；一次空格只前进一次，按键不发起请求、不触发默认滚页。
- 未完成尝试和未输入目标可空格跳过，记录保留实际完成语义，最后一字空格结束本轮。
- 原文内多音待选、仅读音选项可跳过，不造编码或假练习记录。
- 六／八码部件拼字、用户本机四／八码拥有相同空格流程，保留独立记录空间；辅助末字未完成结束后，关闭弹窗可重新练习并正确保存新完成。
- 实体空格、虚拟空格与按钮原生键盘激活不冲突；编辑框空格仍录入文字；修饰键、按住重复、输入法组字不误进度。
- 紧凑码位的可访问名称与实际可见标签一致，专门检查「走 → ZZTR」与「行 → háng → HHII」完成状态。
- 400 目标分页边界可连续前进；320px／375px 和深色模式无横向溢出，放大的编辑框仍可操作。
