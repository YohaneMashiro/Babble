# 常用缺字的下一批规则核验

日期：2026-10-29（Asia/Dubai）。本轮只读复核HY仍缺的升、无、断、见、生、继、夜，以及工程交接中的大。没有将以下可行性候选直接升格为正式答案。

先固定许可笔画／IDS／拆字来源、根映射位置和原创选择，再生成候选，最后才读取固定项目外参照。可行性证据及生成前摘要保存在项目外工程记录；参照未参与选择部件或读音。

| 字 | 已有独立证据 | 仍须完成 |
| --- | --- | --- |
| 无 | 固定Strokes第282行、许可IDS均为一与尢；根表有普通与首末位置变体 | 当前末位覆盖映射会生成与参照不一致的码；必须查清完整尢与相关变体的语境身份，不能按答案改映射 |
| 生 | 固定Strokes第343行；撇与龶的明确笔画选择能生成一致候选 | 逐笔字符串不足以排除其他相同笔画前缀；补几何／规则说明并独立复核后，才可作为策划端点入库 |
| 见 | 固定Strokes第404行；有公开命名部件“见下”事实，一种现代读音候选一致 | 建立独立稳定部件ID、范围和名称，不能直接把见下重命名为儿；另一读音不能随整字一起通过 |
| 大 | 固定Strokes第204行 | 当前部件／规则绑定的候选不一致，不能据此上线；需重查字形和单根规则 |
| 升、断、继、夜 | 许可IDS／拆字资料有组成信息 | 当前固定笔画源缺整字记录；IDS不是笔顺，尚不足以证明取根次序和中间区域，应先补可用笔画／几何来源 |

这批结果说明，补常用字还需要区分**根的字形变体与语境**、**许可笔画事实与取根规则**、**每个读音与每个全码对**。仅得到一个与参照一致的串，不能反过来把任意拆分当作已解释；一条不符也不能靠换成参照字母解决。

下一轮继续以这些具体缺口和规范字差集为依据推进；字体补充只能让字显示出来，不替代本表的编码与教学审查。整体输入覆盖和独立验收仍见[本轮交付](coverage-delivery.md)与[复查](coverage-implementation-check.md)。
