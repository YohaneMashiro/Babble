## 当前状态

**本轮已实现的四码补充、已比较拼字、本机明文库及按需字形链路通过独立复查，结论为限定范围的 Go。** 原数据和记录不回退，六／八码与用户编码可独立练习，来源及未确认候选有明确边界。当前正式四码库为 8,302 字／8,978 个带调读音与全码选项，四码或已确认拼字的并集为 60,891 字。此结论允许交付本轮实现，不代表工程交接的所有扩库项、全部 Unicode 或官方覆盖目标已经完成，也不代替用户接受。

随后独立执行新增 `auxiliary.test.mjs`，9 项全部通过，包括 6／8 位正确前缀、目标命名空间隔离、相邻独立成功、保留历史掌握、延迟基线与排队保存、无效旧记录不改写、失败事务原子性、打开／读／写超时及迟到连接关闭。

新辅助训练的此前审查发现来源展开后重置可漏记协助，以及存储恢复失败后仍可能覆盖旧记录的问题；当前实现已改为重置时关闭来源、先恢复基线再计算写入、恢复失败后只写内存。当前静态接线确认未通过参照的码对只有查询展示；文本默认过滤、手动选用入口也拒绝这类目标。用户库与部件拼字使用独立于旧四码的数据库和目标命名空间，未从用户编码或部件读音推断本字拼音／字根。

本轮另发现文本准备条件仍依赖浏览器旧版 Han 正则、辅助存储缺少超时边界，工程已修改为共享 Unicode18 识别函数和有界存储操作。浏览器实际发现的异步分析缓存、来源披露事件时序、移除用户编码后加载失败及罕见字可访问名称分词问题，也已修复并回归。工程最终全量 181 项测试、严格类型／未使用代码检查、生产构建均通过；本 checker 独立重跑上述 33 项关键单测，并另执行全部数据、Unicode、字体及原有条目等价审计。

源码中的新增网络读取限于按需载入本产品的拼字及字形资料；文章原文与用户文件没有提交或写入学习记录的代码路径。浏览器请求、显式保存／刷新／清除、无效旧记录保留及文章不落盘用例均已核对。

## 字形显示补充复查

浏览器 QA 实际发现稀有样本可练但显示为缺字框，因此本轮增加按需字形兜底，不能只以训练引擎接受编码替代可见性。本 checker 已独立读取固定 Jigmo 2025-09-12 原 ZIP、三份 TTF 的 cmap 和原通知：ZIP 为 35,559,738 B，SHA256 `5744c7386d129475d87607ca66d043c8793c65448adeaedc921b6931890e5d0b`，三份通知与 ZIP 逐字节一致。源字体覆盖 Unicode17 的全部 101,996 个 `Unified_Ideograph`，不含 Unicode18 新增 U+2B81E；实际样本 U+20002、U+20073 均有源字形。

固定源声明 CC0，字体只补显示，不提供读音、编码或取形证据。静态审查的加载器按本产品同源分片读取、字节／SHA 校验并用实际 FontFace 加载，限制并行数，失败及超时可重试；不对每次按键请求字体。默认字形与地区规范字形、IVS及小鹤教学分别界定。

独立审查实际发现原字体的 U+20000 示例与 SIP 字体争用 `080` 文件名，使 manifest 出现重复分片并漏掉该码点。工程已按上游平面归属修复，并在生成器和离线检查中拒绝重复 ID／文件。修复后重新执行全字体审计：111 份锁定输入／产物摘要通过；105 个唯一 WOFF2 文件共 24,926,092 B，实际 cmap 合计 103,382 个码点，与全部清单范围逐项相等，全部映射都有轮廓并存在于固定源中。另将 1,797 个分解后的轮廓样本与对应源 TTF 逐项比较，完全相等。Unicode17 目标 101,996 字全部位于派生 cmap；Unicode18 新增 U+2B81E 仍明确缺字形。证据为 `checker/glyph-font-derived-audit.json`。

最终生产 JS 为 `index-C31KOCG5.js`，2,094,754 B，SHA256 `3455bd16b21c1ae62dc9d5e9b4a4cc4397973182765f6c4097942a5f6cdfa65d`。本 checker 核对实际 dist：104 个拼字 JSON、105 个 WOFF2 与来源锁定字节完全相同；字体清单是编译进 JS 的少量描述数据，字体正文和拼字 JSON 均为外部资产。真实 FontFace、栅格笔画、窄屏、失败重试和源字体缺字边界已通过三引擎用例。

## 最终接线、浏览器与性能

本 checker 逐项读取实际验收映射及其原始 JSON、axe 结果和当前脚本 SHA：Chromium 156.0.8078.4、Firefox 157.0、WebKit 27.2 各六套回归、126 项检查、70 次 axe；合计 **18 套／378 项检查／210 次 axe，均通过且无违规**。覆盖原自由／课程／文本／教学行为，以及新四码、六／八码、无本字读音、只读候选、真实失败重试、方案记录隔离、本机文件边界、UTF-8、刷新／清除、320px、深色和字形可见性。相同构建在普通首屏没有请求补充字体，资料加载后的按键不新增请求。

验收不是把 `final-r6` 目录改称全通过：其中 Firefox 旧自由脚本第一次输入时未等待本地存储就绪和检查焦点，原失败保留。该脚本补齐真实交互前提后，在 `final-r6-free-confirm` 三引擎重跑，明确断言 `storage=saved`、页面有焦点且焦点位于练习区；原 MZJ 等逐键断言没有删除。正式映射使用这三份自由确认，以及 `final-r6` 的其余 15 份通过结果。独立核对记录为 `checker/accepted-browser-audit.json`，完整方法见 [浏览器报告](coverage-engineering-qa.md)。

本 checker 另从十份性能原始结果重算五组旧／新交错探针，核对探针 SHA 和 212 份同类 WSL ext4 静态服务复制文件的字节摘要。导航至首个确认接受按键的中位数由 378.8 ms 到 397.5 ms（+18.7 ms）；加载后各 500 个真实键样本，中位数 31.7／31.6 ms，p95 均 32.4 ms，页面错误和加载后按键请求均为零。它们是本机导航及第二次 RAF 代理，不是现场 INP、精确模块 CPU或低端设备结论，不能据此宣称启动加速。证据为 `checker/performance-audit.json`。

最终源码归档在本报告及其他交付文档落盘后重新生成，按打包白名单与实际文件逐项核对。许可输入、派生资料、程序及通知随源码提供；官方原始参照、用户本机库、上传文章、原 Word 文件和外部测试／构建环境不打包。

## 保留的覆盖与体验缺口

用户的 Unicode 覆盖目标仍未完成：Unicode18 尚缺 41,106 个目标字，已知官方参照并集尚缺 27,059 字；HY 仍有七字／20 次缺口。后续继续处理具体常用字、规范字差集、读音政策、命名部件、许可拆分和参照不一致码，不能把未确认候选直接升格或靠字体补充抬高输入覆盖。详见 [常用缺字队列](common-character-gap-review.md)。

完整取形教学、地区字形、IVS、真实 iOS／读屏及真人学习效果均没有因此完成。Inspector 原 `lookup.status=missing` 的“本地数据库尚未收录”文案只反映原读音／普通四码层；下方已确认拼字仍可查看并练习，应在细节阶段改为明确的分层文案。该文案问题不改变本轮数据资格或评分结果。自动 WebKit 和 axe 均不能代替真实设备及完整无障碍验收。
