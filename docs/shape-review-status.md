## HY 缺字

`data/hy-missing-review.json` 保留 24 字 / 82 次出现的当前 lookup 状态和证据类别：14 项端点推导缺口、10 项命名部件缺口。条目只有字符、次数、`pronunciation-only` 状态及缺口类别，没有官方全码、根、拆分、官方读音或 Chai 候选。出现次数可用 `npm run audit:coverage` 复算；类别沿用研究交接的分组，表示下一步需要核查的证据，不是训练答案。

正式接入任何缺字前，仍须同时提供：明确许可的根／笔画／命名部件来源；小鹤规则应用理由；同一拆分里的首末边界；对固定外部参考的独立核对；现代读音与声韵表匹配的完整四码；对应来源通知、生成器和新锁；旧数据无丢失与无改错的回归。命名部件不得改成相似 Unicode 字符来凑码。

Chai 的 5/24 目标和 6/10 控制字结果维持研究试验状态。未确认的远程字形许可、未完成的小鹤规则配置和根标签不一致仍是接入门槛，本轮未将这些候选升格为训练数据。官方原文件及详细外部答案报告不进入产品或源码包。
