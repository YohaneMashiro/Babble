# 官方查形快照增量校对

`scripts/official-ix-audit.mjs` 是构建资料的只读校对工具。它向固定的
<https://flypy.cc/ix/ixdata.json> 发出一次公开 GET，之后在本机与当前实际训练库比较。
不逐字请求页面、不修改训练库或来源锁，也不生成缺失的字根和编码。

需要项目的 Node.js 22.12+ 与 `npm ci`。正式网页运行时不需要此工具或联网查询。

```bash
# 首次下载；之后携带 ETag / Last-Modified 条件请求
node scripts/official-ix-audit.mjs

# 使用已有缓存，不发网络请求
node scripts/official-ix-audit.mjs --offline

# 自选项目外的缓存；详细差异也必须保存在项目外
node scripts/official-ix-audit.mjs \
  --cache-dir /tmp/babble-ix-cache \
  --report /tmp/babble-ix-report.json

# 完全离线读取两份项目外 JSON，比较版本与当前训练库
node scripts/official-ix-audit.mjs \
  --reference /tmp/new-ixdata.json \
  --baseline /tmp/old-ixdata.json \
  --report /tmp/babble-ix-diff.json
```

默认缓存目录为 `${XDG_CACHE_HOME:-$HOME/.cache}/babble/official-ix`。原始 JSON
按 SHA256 保存成不可覆盖的历史文件名，由原子更新的 `current.json` 指向当前版本。
元数据记录 URL、原始字节数与摘要、首次获取时间、最近检查时间、ETag、Last-Modified、
解析器版本与前一版本摘要。304 复用并重新校验原始快照，不伪造新的获取时间。
`--reference` 表示使用外部文件，`fetchedAt`、ETag 等未知信息保留为 `null`，不会假称本次已联网。

请求超时 20 秒，解码后的正文最多 4 MiB；HTTP 错误、意外内容类型、无效 UTF-8 / JSON、
字段结构变化、超限或网络失败均报错退出，保留旧快照与指针。完整解析通过后才切换指针。
离线模式若没有缓存会明确失败，不自行回退到网络。工具不接受其他抓取 URL，也不跟随重定向。
并发更新使用排他锁；若进程被强制终止，先确认没有其他审计运行，再手动移除缓存中的
`.update.lock`。工具不会自动删除历史快照。

原始 JSON、外部参考文件与含官方字段的详细报告均须位于项目外，包括符号链接解析后的路径。
`--report` 不能指向输入参考文件、基线文件或缓存目录内的任意位置。终端只输出元数据和统计，
不打印逐字官方字段。工具不会读取或上传文章内容。官方 JSON 的独立开放数据许可尚未确认，
不要把原始快照、详细报告移入 `data/`、`tools/` 或源码分发包。

## 比较的含义

- 版本差异分别报告新增字、删除字，以及编码、首末根、拆分、读音、标记和异常的变化。
  编码和读音的重排不算语义变化；首末根和拆分保持顺序。标记按所属编码比较，能发现同一批
  `-` / `+` / `*` 从一个编码移动到另一个编码，未知符号记为异常。
- 运行库从 Vite 的本地 SSR 模块接口加载，没有 HTTP 服务；比较的是 `TRAINING_ENTRIES`，
  不是另做一套模拟码表。现代来源读音调用产品现有 `explainSound` 与已审计的键位映射。
  官方编码与读音绝不按数组位置配对。
- 根的语义比较仅去掉现有锁定验证器允许的尾随拼音注记，例如单个汉字后附拉丁拼音。
  完整原标签仍保留在差异报告中；“见下”等命名部件不会猜换成另一个字根。
- 对本地缺字，分类优先顺序是：根数量异常、没有匹配的现代读音编码前缀、命名部件、
  尚缺可采用的来源推导。读音差异再按是否已有本地取形轨迹分列，避免把不受当前读音政策
  支持的官方容错或罕见编码直接当作训练答案。
